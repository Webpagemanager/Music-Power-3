Music Power 3

A lightning-fast, highly customizable native Windows desktop music player built with WinUI 3.

Download for Windows Version 2.2.0.0 • Requires Windows 10 (Build 19041) or later

Why Music Power 3?

⚡ High Performance

Optimized for lower-end systems, with RAM usage rarely reaching 100 MB. Instant search, filtering, and a lightning-fast JSON library cache.

🎛️ Deep System Integration

Full support for Windows System Media Transport Controls. Media keys, headset buttons, and the volume flyout work out of the box.

🎵 Advanced Playback

Standard controls, repeat modes, shuffle memory, and a unique "random date range" filter to limit playback to music from a certain period.

🏷️ Powerful Metadata Editing

Built on TagLib#. Batch edit titles, artists, albums, years, and genres. Fetch, replace, or remove embedded album art smoothly.

✨ Custom UI

Featuring a hand-crafted scrubbable AudioProgressBar for horizontal/vertical layouts, live accent color picking, and adjustable UI scaling.

🎧 Broad Format Support

Natively plays MP3, FLAC, WAV, M4A, AAC, OGG, and WMA files seamlessly.
